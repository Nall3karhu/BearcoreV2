# BearCore Studio V0.1

BearCore Studio on BearCoren ensimmäinen graafinen kehitysympäristö.

## Käynnistys

Aja BearCore V2 -projektin juuresta:

    python studio.py

## V0.1 sisältää

- BearCore Chat
- BearCore Start / Stop
- Smart Memory -näkymä
- Memory importance -näyttö
- Tool Manager -näkymä
- Git status
- Loki
- Ei ulkoisia GUI-riippuvuuksia: käyttää Pythonin Tkinteriä

## Sijoitus

Kopioi nämä BearCore V2 -projektin juureen:

    studio.py
    studio/

Eli esimerkiksi:

    BearCore_V2/
    ├── core/
    ├── modules/
    ├── tests/
    ├── main.py
    ├── studio.py
    └── studio/
        ├── __init__.py
        └── app.py
